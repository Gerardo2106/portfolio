# Gerardo Martinez | Portfolio

My personal portfolio site. It has a quick intro about me, a few projects I've worked on, the tools I use, and how to reach me.

**Live site:** https://gerardo2106.github.io/portfolio/

## What's on it

- **About:** who I am and what I like building, plus links to my GitHub, LinkedIn, and resume
- **Projects:** a music discovery app, a quotes admin panel, a solar system site, and a machine learning project on amusement park injuries, each with links to the code (and a live demo where there is one)
- **Skills:** the languages and tools I use for web, data, and systems work
- **Contact:** my email

## Built with

- HTML and CSS, no frameworks
- Google Fonts (Bricolage Grotesque, Instrument Sans, JetBrains Mono)
- Hosted on GitHub Pages

It also switches to a dark theme automatically if your device is set to dark mode.

## Running it locally

There's nothing to install. Just download or clone the repo and open `index.html` in your browser.

    git clone https://github.com/Gerardo2106/portfolio.git
